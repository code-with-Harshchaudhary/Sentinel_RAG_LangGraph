# Security policy

Do not open a public issue for a suspected vulnerability. Use the repository's private security-advisory form at:

`https://github.com/code-with-Harshchaudhary/Sentinel_RAG_LangGraph/security/advisories/new`

Include the affected version, reproduction steps, impact, and any suggested mitigation. Report vulnerabilities in third-party dependencies to their maintainers as well.

Only the latest release is supported with security fixes. Never commit `.env`, provider credentials, database passwords, TLS private keys, or exported production data.
