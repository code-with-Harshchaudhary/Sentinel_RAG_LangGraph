# Research & Papers card artwork

Mode: built-in image_gen. Default: generate/product-mockup. Hover: edit/precise-object-edit using the default image as edit target. Exactly one tool call per asset.

## Default prompt

Use case: product-mockup
Asset type: original portrait bitmap artwork for the default state of a portfolio Research & Papers card, 3:4 aspect ratio.
Scene/backdrop: pale lavender-gray matte studio surface, quietly architectural, uncluttered.
Subject: close cropped sculptural stack of off-white research papers and a slim off-white monograph, charcoal ink technical node-link diagram on its cover and one small acid-lime indexing tab.
Style/medium: premium photorealistic editorial 3D print-object photography with tactile realistic uncoated paper fibers, fine page edges, crisp thin drafting lines and beautiful grounded shadows.
Composition/framing: centered object, elegant three-quarter overhead camera, stack slightly diagonally placed; strong central composition filling roughly 70 percent of frame, ample clean margins. Portrait 3:4 image.
Lighting/mood: soft directional studio daylight, refined and precise, restrained contrast.
Color palette: off-white, pale lavender-gray, charcoal ink, a single tiny acid-lime accent; designed to accompany a black charcoal technical dotted-grid portfolio interface.
Text (verbatim): "RESEARCH" and "PAPERS" on separate lines in clean charcoal monospaced uppercase type, readable. These are the only words.
Constraints: simple sparse node-link technical diagram printed or embossed on cover; no fabricated author, date, publication metrics or journal branding. This is conceptual collection artwork, not a publication claim.
Avoid: UI screenshots, card borders, phones, devices, journal logos, invented certificates, watermarks, extra props, extra text.

## Hover prompt

Use case: precise-object-edit
Asset type: original portrait bitmap artwork for the hover state of a portfolio Research & Papers card, coordinated with the supplied default artwork.
Input images: Image 1 is the edit target and exact reference for the paper object, camera, lighting, materials, background, and palette.
Primary request: create a coordinated hover variation by opening the slim monograph and separating a few of its upper paper leaves to reveal a beautiful precise node-link knowledge-graph print across the newly visible off-white page, with one small acid-lime bookmark. The open/partly fanned page construction must be physically plausible, elegant, and feel like the next moment in this exact same still life.
Constraints/invariants: preserve the exact pale lavender-gray studio surface, off-white stacked papers, charcoal ink, tactile paper fibers, softly directional daylight and shadows, portrait 3:4 framing, diagonal central orientation and three-quarter overhead camera angle. Keep sufficient clean margins; do not add unrelated objects. Only change the upper monograph to its opened or separated-page state. No new colors. Single small lime accent. Keep the knowledge graph sparse, precise, node-and-link technical drafting.
Text: Prefer no text on revealed interior page; if any cover text remains visible it must read only "RESEARCH" and "PAPERS". No additional words.
Style/medium: premium photorealistic editorial 3D print-object photography. Conceptual research collection artwork, no claims of peer reviewed publication.
Avoid: UI screenshots, card borders, phones, devices, journal logos, fabricated author/publication metrics, invented certificates, extra props, watermarks, excessive flying pages or impossible folds.
